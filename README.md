# 角色卡管理 (Char Manager)

一款用于 SillyTavern / TauriTavern 的角色卡管理扩展。以卡片网格浏览全部角色，支持搜索、收藏、按标签筛选、排序与一键切换，并提供详情预览、导出、复制与删除等管理操作。

与 [API 快切 (st-api-switcher)](https://github.com/idx425/st-api-switcher) 同一套视觉体系。

## 功能

- **文件夹归纳**：自建文件夹收纳角色卡（新建/重命名/删除），点选文件夹芯片快速筛选，「未归类」一键定位散卡；归类数据存于酒馆设置，不修改角色卡文件
- **分页浏览**：默认 20 张/页（可切 10/50），首页/上一页/下一页/末页翻页，不再一屏塞入全部卡片
- **批量管理**：多选模式下点选任意多张卡，一次性移入文件夹 / 收藏 / 导出 / 删除（多重确认），支持全选本页
- **接管原生角色面板**：管理器直接嵌入并替换酒馆自带的角色列表界面，点开角色面板看到的就是管理器；面板右上角一键切回原生视图，也可在扩展设置中关闭接管
- **快捷操作栏**：导入卡片（PNG/JSON）、URL 导入、新建角色、随机抽一张开聊、一键回到上个聊过的角色、把当前筛选结果全部导出备份
- **管理器面板**：卡片网格展示全部角色（头像大图），手机 / 平板 / 桌面自适应列数
- **搜索**：按名称、作者、标签、描述实时过滤
- **收藏与最近**：星标收藏；自动记录最近聊天过的角色，一键筛选
- **标签筛选**：读取酒馆自带的角色标签体系，点选标签过滤
- **排序**：最近聊天 / 名称 / 添加时间，点击循环切换
- **一键切换**：点击卡片直接切换到该角色并进入聊天
- **详情预览**：大图、作者、版本、标签、字数统计、角色描述与开场白预览
- **卡片操作**：导出 PNG 角色卡（含完整数据，可导入任何酒馆）、创建副本、删除（多重确认）
- **快捷入口**：聊天输入框旁魔棒菜单；斜杠命令 `/charman`（打开管理器）、`/charswitch 角色名`（直接切换，别名 `/ccs`）
- **自动更新提醒**：启动时检测新版本并弹出通知，此后每 45 分钟自动复查、打开管理器时也会顺带检查，长时间开着酒馆也不会错过更新；点击通知即可一键更新，版本检测走 CDN 兜底

## 安装

扩展面板 → **安装扩展 (Install extension)** → 粘贴：

```
https://github.com/idx425/st-char-manager
```

安装后刷新页面，在扩展设置中找到「角色卡管理」，或直接点魔棒菜单里的入口。

## 环境要求

- SillyTavern 1.12+，TauriTavern 可用
- 收藏与最近记录存于本机酒馆设置（`settings.json`），不修改角色卡文件本身
- 删除操作调用酒馆后端接口，不可恢复，请谨慎确认

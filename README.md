# 角色卡管理 (Char Manager)

一款用于 SillyTavern / TauriTavern 的角色卡管理扩展。以卡片网格浏览全部角色，支持搜索、收藏、按标签筛选、排序与一键切换，并提供详情预览、导出、复制与删除等管理操作。

与 [API 快切 (st-api-switcher)](https://github.com/idx425/st-api-switcher) 同一套视觉体系。

## 功能

- **隐藏原生热切换栏**：接管原生角色面板时，彻底移除顶部 redundant 快捷热切换栏 (`:三` 与 `★ 收藏角色以将它们添加到快速热切换区`)，平滑提拉当前角色名与 Token 计数，大幅释放垂直显示空间，且绝不误伤顶栏主导航图标。
- **零抖动优化 (Zero-Jitter Engine)**：彻底重构 GPU 图层与 modal 动画过渡，移除高频 JS 布局轮询与 DOM style 强写，流畅不卡顿。
- **文件夹归纳**：自建文件夹收纳角色卡（新建/重命名/删除），点选文件夹芯片快速筛选，「未归类」一键定位散卡；归类数据存于酒馆设置，不修改角色卡文件。
- **分页浏览**：默认 24 张/页（可切 12/24/48，始终为 3 的倍数），首页/上一页/下一页/末页翻页，不再一屏塞入全部卡片。
- **批量管理**：多选模式下点选任意多张卡，一次性移入文件夹 / 收藏 / 导出 / 删除（多重确认），支持全选本页。
- **快捷栏折叠**：支持一键折叠/展开顶部 6 个快捷按钮（导入/URL/新建/随机/继续/备份），大幅省出下方网格显示高度。
- **浅色/暗色主题**：支持暗色玻璃 (Dark Glass) 与浅色明亮 (Light Mode) 两种风格切换，浅色酒馆背景下高对比度清晰易读。
- **紧凑模式 (Compact)**：可一键开启紧凑/缩微模式，调小卡片与间距，一屏轻松容纳更多角色卡。
- **接管原生角色面板**：管理器直接嵌入并替换酒馆自带的角色列表界面，点开角色面板看到的就是管理器；面板右上角一键切回原生视图，也可在扩展设置中关闭接管。
- **快捷操作栏**：导入卡片、URL 导入、新建角色、随机抽一张开聊、一键回到上个聊过的角色、把当前筛选结果全部导出备份。
- **内置导入器**：自带文件选择界面，支持 PNG / JSON / WEBP / CHARX / YAML 五种格式、可一次多选，导入后自动刷新列表。
- **高清卡面**：网格直接加载角色卡原图（懒加载），不再使用发糊的小缩略图。
- **搜索与标签**：按名称、作者、标签、描述实时过滤，标签与文件夹支持触屏横向流畅滑动。
- **收藏与最近**：星标收藏；自动记录最近聊天过的角色，一键筛选。
- **一键切换**：点击卡片直接切换到该角色并进入聊天；可在设置中改为「点卡片先看详情」防误触。

## 安装

扩展面板 → **安装扩展 (Install extension)** → 粘贴：

```
https://github.com/idx425/st-char-manager
```

安装后刷新页面，在扩展设置中找到「角色卡管理」，或直接点魔棒菜单里的入口。

- **隐藏原生热切换栏 (`#CharListButtonAndHotSwaps`)**：接管原生角色面板时，自动隐藏顶部的 `:三` 按钮与 `★ 收藏角色以将它们添加到快速热切换区` 提示栏，将当前角色名（如《与炮友系青梅竹马...》）与 Token 计数整体平滑向上提拉，释放顶部高度，同时确保不影响顶栏主导航抽屉图标。
- **彻底消除残留抖动问题 (Zero-Jitter Engine)**：
  - 彻底重构 `.ccm-overlay` 弹窗与 `.ccm-modal-box` 硬件加速过渡动画，消除 CSS `transform: none !important` 与 `@keyframes` 冲突导致的开合帧跳跃与卡顿。
  - 移除卡片原图 `will-change: transform`，降低 GPU 图层合成开销，提升大图列表滚动流畅度。
  - 防抖处理主题切换监听器 `checkThemeChanged()`，避免高频 DOM 变量刷新引发全页重排 (Reflow) 与抖动。
  - 优化切卡时的抽屉平滑关闭逻辑 (`closeCharDrawer()`)，消除多重定时器连续触发 click 导致的动画重叠抖动。
- **修复 DOM 重复 ID Bug**：修复 `openManager()` 弹窗中重复渲染 `id="ccm_toggle_edit_btn"` 按钮图标的问题。
- **全端适配**：通用端完美适配 PC、Mac、平板与大屏设备，无缝兼容 ST 酒馆 (SillyTavern) 与 TT 酒馆 (TauriTavern)。
